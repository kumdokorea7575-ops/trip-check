🏫 처음 쓰시나요?

먼저 우리 반 번호와 명단을 입력해 주세요. 명렬표에서 이름을 복사해 붙여넣으면 돼요.

📍 어디에서 인원체크를 하나요?

장소를 적고 시작을 누르면 시작 시각부터 확인 시간이 기록돼요.

이름을 누르면 확인 (다시 누르면 취소) · 아래 버튼으로 미참여 지정 (새 인원체크를 해도 유지돼요)

☁ 구글시트 연결

연결하면 인원체크 기록이 구글시트에 반별 탭(예: 8반 기록, 8반 통계)으로 자동 저장돼요. 담임 선생님이 받은 연결 링크로 열었다면 이미 연결돼 있어요.

📲 담임 선생님께 보내기

아래 링크를 담임 선생님께 보내세요. 링크를 열고 반·명단만 입력하면 되고, 기록은 이 구글시트에 반별로 모여요. 링크를 연 다음 브라우저 메뉴에서 홈 화면에 추가를 누르면 돼요.

🗑 이 기기 기록 지우기
